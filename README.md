# Driftless Area Pest Control

Next.js conversion of the original static homepage, with the same design, styles, and interactions.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build

## Structure

- `src/app/` — App Router layout and home page
- `src/components/HomePage.tsx` — homepage UI + interactions
- `src/app/globals.css` — original design system CSS
- `public/images/` — site images
- `html-original/` — archived static HTML source files
